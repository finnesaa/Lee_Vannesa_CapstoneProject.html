# Lee_Vannesa_CapstoneProject.html
Smile School is an education website that is designed to help children learn the importance of brushing and flossing their teeth. Through interacitve activities, simple explanations, and step-by-step guides, the site teaches healthy dental habits in a fun and engaging way.



Project Overview 
---------------------------
This project demonstrates web development skills using:
- HTML for structure
- CSS for styling and layout
- JavaScript for interactivity
The design focuses on accessibility, simplicity, and child-friendly visuals.

The website includes:
- Educational guides on brushing and flossing
- Interactive activities for kids
- Images, icons, and engaging illustrations
- A clean layout suitable for young audiences

Features
---------------------------
- Interactive buttons and activities
- Accessible design
- Responsive layout
